Natsuki Visual - source project
Target: Minecraft Java 1.21.11 / Fabric / Java 21

GUI key: Right Shift.
Menu keyboard shortcuts:
1 = toggle watermark
2 = toggle FPS/Ping
3 = toggle block-outline option (placeholder toggle only; outline renderer not implemented).

This is a source project, not a compiled or tested JAR. Dependency versions may need adjustment
and Gradle (9.x) must resolve Fabric/Minecraft dependencies online before compiling.
Build: gradle build (or use a Gradle wrapper in an environment with Gradle installed).
